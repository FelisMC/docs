# License {#license}

This page describes the license Felis is released under and its main requirements for distributing and deploying Felis. It is for readers who distribute, modify or run Felis as a network service.

## AGPL-3.0-only {#agpl}

Felis is released under the GNU Affero General Public License, version 3 (AGPL-3.0-only). The full text is in [LICENSE.txt](/LICENSE.txt); the original in the repository is on [GitHub](https://github.com/FelisMC/Felis/blob/main/LICENSE).

## Main obligations {#obligations}

1. **Derivative works use the same license**: when you distribute Felis or software derived from it, release it under AGPL-3.0 and keep the original copyright and license notices.
2. **Network services must offer the source**: under section 13 of the AGPL, if you offer a modified Felis to others over a network, you must provide those users with the complete source of the modified version, even if you distribute no binary. This is the main difference between the AGPL and the GPL. Felis provides its panel and game entry over the network, so a deployment that runs a modified Felis is usually subject to this clause.
3. **Disclaimer**: Felis is provided "as is", without warranty of any kind; the authors accept no liability for the consequences of using it.
