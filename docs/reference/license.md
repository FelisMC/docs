# 开源协议 {#license}

本页说明 Felis 采用的许可证及其对分发和部署 Felis 的主要要求。面向分发、修改或以网络服务形式运行 Felis 的读者。

## AGPL-3.0-only {#agpl}

Felis 采用 GNU Affero 通用公共许可证第 3 版（AGPL-3.0-only）发布。许可证全文见 [LICENSE.txt](/LICENSE.txt)，仓库中的原文见 [GitHub](https://github.com/FelisMC/Felis/blob/main/LICENSE)。

## 主要义务 {#obligations}

1. **衍生作品须采用相同许可证**：分发 Felis 或基于 Felis 的衍生软件时，须以 AGPL-3.0 发布，并保留原有的版权声明和许可证声明。
2. **网络服务须提供源码**：AGPL 第 13 条规定，通过网络向他人提供经修改的 Felis 时，即使不分发任何二进制文件，也须向这些用户提供修改版本的完整源码。这是 AGPL 与 GPL 的主要区别。Felis 的面板和游戏入口都通过网络提供，因此运行修改版 Felis 的部署通常都适用此条款。
3. **免责声明**：Felis 按“原样”提供，不附带任何形式的担保；作者不对使用 Felis 产生的后果承担责任。

::: info
本页只概括主要义务，权利与义务以许可证原文为准。
:::
